### Стек:
* **React + TypeScript + Vite**
* **CSS Modules**

### Реализовано:
* **Бесконечный скролл** (через нативный Intersection Observer).
* **Избранное** (сохранение в LocalStorage через Context API).
* **Адаптивная верстка** (от мобильных до десктопа).
* **Плавная загрузка** (скелетоны и fade-in для картинок).
* **Обработка ошибок** и пустых состояний.
